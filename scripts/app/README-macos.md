# GitLib {{version}} для macOS

Персональная библиотека GitHub-репозиториев. Node.js устанавливать не нужно — всё внутри `GitLib.app`.

## Запуск

1. Перетащите `GitLib.app` в «Программы».
2. Двойной клик по GitLib. В строке меню (вверху справа) появится значок с книгами, браузер откроется сам на
   <http://localhost:4817>. Окна терминала и иконки в Dock нет.
3. При первом запуске macOS скажет, что не может проверить разработчика: приложение не подписано
   сертификатом Apple. Откройте «Системные настройки» → «Конфиденциальность и безопасность» → внизу
   «GitLib заблокировано…» → «Всё равно открыть». Или один раз в Терминале:
   `xattr -dr com.apple.quarantine /Applications/GitLib.app`

## Значок в строке меню

«Открыть GitLib», «Папка с данными», «Открывать при входе в систему», «Выключить GitLib».
Повторный двойной клик по GitLib.app при работающем GitLib просто откроет браузер.

## Где данные

`~/Library/Application Support/GitLib`: база `gitlib.sqlite`, аватары, `settings.json`
(там же токен GitHub и ключ LLM — не пересылайте эту папку другим) и журнал сервера `gitlib.log`.

## Обновление

Выключите GitLib через значок и замените `GitLib.app` новым — данные лежат отдельно и сохранятся.
