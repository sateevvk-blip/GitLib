# GitLib {{version}} для Windows

Персональная библиотека GitHub-репозиториев. Node.js устанавливать не нужно — всё внутри.

## Запуск

1. Распакуйте архив в любую папку, например `Документы\GitLib`. Файлы `GitLib.exe` и `gitlib-server.exe`
   должны лежать рядом.
2. Двойной клик по `GitLib.exe`. В трее (у часов) появится значок GitLib, браузер откроется сам на
   <http://localhost:4817>. Окна консоли нет.
3. При первом запуске Windows может показать «Система Windows защитила ваш компьютер» — файлы не подписаны
   сертификатом. Нажмите «Подробнее» → «Выполнить в любом случае».

## Значок в трее

- Щелчок по значку — открыть GitLib в браузере.
- Меню (правая кнопка): «Открыть GitLib», «Папка с данными», «Запускать вместе с Windows», «Выключить GitLib».
- Повторный запуск `GitLib.exe` при работающем GitLib просто откроет браузер.
- Если значок спрятан, нажмите стрелку «^» у часов; перетащите значок на панель, чтобы он был виден всегда.

## Где данные

В папке `data\` рядом с `GitLib.exe`: база `gitlib.sqlite`, аватары, `settings.json`
(там же токен GitHub и ключ LLM — не пересылайте эту папку другим) и журнал сервера `gitlib.log`.
Другая папка — переменная `GITLIB_DATA_DIR`, другой порт — `GITLIB_PORT`.

## Обновление

Выключите GitLib через значок в трее, замените `GitLib.exe` и `gitlib-server.exe` новыми, папку `data\` оставьте на месте.
