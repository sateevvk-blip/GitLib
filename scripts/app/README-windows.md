# GitLib {{version}} для Windows

Персональная библиотека GitHub-репозиториев. Node.js устанавливать не нужно — всё внутри `GitLib.exe`.

## Запуск

1. Распакуйте архив в любую папку, например `Документы\GitLib`.
2. Двойной клик по `GitLib.exe`. Браузер откроется сам на <http://localhost:4817>.
3. При первом запуске Windows может показать «Система Windows защитила ваш компьютер» — файл не подписан
   сертификатом. Нажмите «Подробнее» → «Выполнить в любом случае».

Окно консоли не закрывайте, пока пользуетесь приложением: закрыли окно или нажали Ctrl+C — GitLib остановлен.
Повторный запуск при работающем GitLib просто откроет браузер.

## Где данные

В папке `data\` рядом с `GitLib.exe`: база `gitlib.sqlite`, аватары и `settings.json`
(там же токен GitHub и ключ LLM — не пересылайте эту папку другим). Другая папка — переменная `GITLIB_DATA_DIR`,
другой порт — `GITLIB_PORT`.

## Обновление

Замените `GitLib.exe` новым, папку `data\` оставьте на месте.
