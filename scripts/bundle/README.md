# GitLib {{version}} — персональная библиотека GitHub-репозиториев

Вставляете ссылку на репозиторий — GitLib забирает описание и README с GitHub, по желанию составляет
русскоязычную AI-сводку и кладёт проект в локальную библиотеку с поиском, заметками, темами и коллекциями.
Всё хранится у вас на компьютере.

## Установка

1. Установите **Node.js 22 LTS** (22.13 или новее) с <https://nodejs.org>, если его ещё нет.
   Проверить: `node -v` в терминале.
2. Распакуйте архив в любую папку, например `Документы/GitLib`.
3. Запустите:
   - **Windows** — двойной клик по `GitLib.cmd`;
   - **macOS** — двойной клик по `GitLib.command` (если система не пускает: правый клик → «Открыть»,
     или в Терминале `sh gitlib.sh`);
   - **Linux** — `sh gitlib.sh`.
4. Браузер откроется сам на <http://localhost:4817>. Окно консоли не закрывайте, пока пользуетесь
   приложением; закрыли окно или нажали Ctrl+C — GitLib остановлен.

Ничего устанавливать через npm не нужно — все зависимости уже внутри.

## Настройка

Всё — на странице **Настройки** в приложении:

- **GitHub** — без токена GitHub даёт 60 запросов в час (≈20 добавлений). Для большего создайте
  fine-grained token с доступом только к публичным репозиториям и вставьте его в настройки.
- **AI-анализ** — любой OpenAI-совместимый API: OpenAI (`https://api.openai.com/v1`), OpenRouter
  (`https://openrouter.ai/api/v1`), локальные Ollama (`http://localhost:11434/v1`) или LM Studio
  (`http://localhost:1234/v1`). Без него приложение полностью работает, просто без сводок.

Другой порт: задайте переменную окружения `GITLIB_PORT`, например `GITLIB_PORT=5000 sh gitlib.sh`
или в Windows `set GITLIB_PORT=5000` и затем `GitLib.cmd` в той же консоли.

## Где данные

В папке `data/` рядом с этим файлом: база `gitlib.sqlite`, аватары и `settings.json`
(там же токен GitHub и ключ LLM — не пересылайте эту папку другим).

## Обновление до новой версии

1. Остановите GitLib.
2. Распакуйте новый архив в новую папку и перенесите в неё папку `data/` из старой.
3. Запустите как обычно.

Для переноса библиотеки на другой компьютер или подстраховки есть «Экспорт» в приложении — JSON-файл,
который потом загружается через «Импорт». Секреты в экспорт не попадают.
