## [Unreleased]

### Added
- Лендинг GitLib: `docs/GitLib лендинг.html` — автономная страница-презентация (скриншоты обеих тем, спрайты маскотов и логотип вшиты как data:URI, шрифты с Google Fonts): возможности, поиск, заметки и статусы, коллекции, настройка модели, офлайн и экспорт, шаги после вставки ссылки, запуск. Переключатель тёмной/светлой темы, адаптивная вёрстка, `prefers-reduced-motion`. Без коммерческих блоков и контактов.
- Заставка при открытии приложения (`src/client/intro/`): изометрический квартал по референсу `дизайн/0cf0fbf7106f91be89882c480e2978d3.jpg` — синее кубическое здание-библиотека с арками на террасе, белые кварталы, пунктирные улицы с именами веток, деревья и прохожие. К воротам подъезжает машина, пассажир выходит и через ворота прямо заходит во входную арку левого фасада, камера за это время плавно наезжает на здание (≈6 с). Тени строятся от источника света (выпуклая оболочка основания), терраса обнесена оградой по периметру; у прохожих, машин и деревьев — силуэты с руками, стёклами, колёсами и кронами. Геометрия (`iso.ts`) и временная шкала (`timeline.ts`) — чистые функции, актёры двигаются через `requestAnimationFrame` без перерисовки React. Один раз за сессию вкладки, пропуск — кнопка или Esc, при `prefers-reduced-motion` не показывается; маскот здоровается после заставки. Стоп-кадр для настройки сцены: `/?intro=<мс>`. Тест `tests/intro.test.ts`.
- Позы Глобуса и Карася из новых листов `маскот/Глобус.png`, `Глобус 2.png`, `Карась.png`. Глобус (8 поз): кофе — в покое, ноутбук — думает, зевает на ходу — спит, бежит с бумагами — ищет, палец вверх, пожимает плечами, рука-лицо, руки скрещены. Карась (6 поз): стоит, идёт, бежит, прыгает, сидит, пинает. Раскладка по настроениям — `CHARACTER_POSES` в `characters.ts`.
- Анимации поз Глобуса и Карася (`.m-act` в `global.css`): Глобус отхлёбывает кофе, стучит по клавишам, потягивается, качает головой, пожимает плечами, подпрыгивает на бегу; Карась покачивается, ходит вразвалочку, прыгает с приседанием, болтает ногами, пинает. Раскадровка из нескольких поз: Карась шагает (идёт ↔ бежит), на празднике оба танцуют. При `prefers-reduced-motion` виден только первый кадр.
- Значок в трее вместо окна консоли. Windows: `GitLib.exe` — программа для трея (C#, `scripts/app/windows/GitLibTray.cs`, собирается встроенным в Windows `csc.exe`, иконка `gitlib.ico` из логотипа) запускает `gitlib-server.exe` без окна, пишет его вывод в `data\gitlib.log`, меню: «Открыть GitLib», «Папка с данными», «Запускать вместе с Windows» (ключ `HKCU\…\Run`), «Выключить GitLib»; повторный запуск открывает браузер. macOS: `GitLib.app` — значок в строке меню (Swift, `scripts/app/macos/GitLibMenu.swift`) с тем же меню, автозапуск через LaunchAgent, повторный двойной клик открывает браузер.
- `POST /api/shutdown` — корректная остановка сервера для значка в трее; только с заголовком `X-GitLib-Shutdown: 1` (чужая страница не отправит его без CORS) и только когда сервер запущен через `index.ts`. Тест в `tests/api.test.ts`.
- `GitLib.exe` (Windows) и `GitLib.app` (macOS) без установленного Node: `npm run bundle:app` (`scripts/build-app.mjs`) вшивает сервер (esbuild, один CommonJS-файл) и клиент в копию Node через Single Executable Applications и собирает `release/gitlib-<версия>-windows-x64.zip` / `-macos-arm64.zip` / `-macos-x64.zip`. Точка входа `src/server/desktop.ts`: клиент распаковывается в `<данные>/.client/<хеш>`, повторный запуск только открывает браузер, предупреждение про экспериментальный `node:sqlite` скрыто. Данные: Windows — `data\` рядом с exe, macOS — `~/Library/Application Support/GitLib`. Каждая платформа собирается на своей ОС (значок в трее компилируется её инструментами) — workflow `.github/workflows/app.yml` собирает Windows и macOS на своих раннерах и прогоняет smoke, в том числе на Intel Mac.
- `npm run smoke -- --exe <путь>` проверяет собранный GitLib.exe или `gitlib-server` из GitLib.app.
- Оценка и план миграции хранилища на PocketBase: `docs/pocketbase-migration.md`. Вывод — для цели «запуск без терминала» миграция не нужна, рекомендован `GitLib.exe` (Node SEA), запуск без консоли и автозапуск; план на PocketBase (Go-бинарник) сохранён на случай синхронизации или нескольких пользователей.
- Анимации ухода: тост уходит к краю за 150 мс перед удалением, реплика маскота гаснет за 150 мс, диалог подтверждения появляется (фон 250 мс, окно 350 мс) и уходит при отмене, Esc или клике по фону за 250 мс. Длительности JS берёт из CSS-токенов (`cssDuration()`, хук `usePresence()` в `src/client/lib/motion.ts`). Тест `tests/toast.test.ts`.
- Аудит анимаций по [LottieFiles/motion-design-skill](https://github.com/LottieFiles/motion-design-skill): `docs/motion-audit.md` — 10 находок (каскад карточек длиннее бюджета, нет `prefers-reduced-motion` вне маскота, «прыгающий» подъём карточки при наведении, нет анимаций ухода, нет токенов длительности) и порядок исправлений.
- Переносимый бандл для друзей и коллег: `npm run bundle` (`scripts/pack.mjs`) собирает `release/gitlib-<версия>.zip` с production-сборкой, серверными зависимостями и лаунчерами `GitLib.cmd` / `GitLib.command` / `gitlib.sh` (шаблоны в `scripts/bundle/`); получателю нужен только Node.js 22.13+. Лаунчер проверяет версию Node, открывает браузер, не дублирует уже запущенный экземпляр и приглушает лог запросов. Папка `release/` в `.gitignore`.
- Навык Claude Code `ui-ux-pro-max` (`.claude/skills/ui-ux-pro-max/`): справочник по UI/UX — стили, палитры, шрифтовые пары, гайдлайны, стеки.
- Шесть маскотов из референса `маскот/aaccbfbeec00f7be2cac9b0693ab91ae.jpg` — Банан, Баскет, Глобус, Кот, Карась, Лимон — у каждого свои реплики (приветствие, ответ на клик, «защекотали», пробуждение, фирменная похвала).
- Выбор маскота в «Настройках» (раздел «Маскот», `/settings#mascot`): карточки с персонажами, выбор запоминается в браузере (`gitlib.mascot`); рядом — кнопки «Посмотреть реакции» для всех настроений.
- Новые настроения маскота: wink, cool, grumpy, shy, laugh, dizzy, wave, party (всего 16) с реквизитом: очки, пар, пот, конфетти, звёздочки, «ха-ха».
- Новые реакции: приветствие по времени суток один раз за сессию (при первом запуске — подсказка выбрать напарника со ссылкой в настройки), праздник на круглых числах репозиториев (1, 10, 25, 50, 100…), дремота после четырёх минут бездействия и пробуждение по движению, эскалация при частых кликах (смех → головокружение → ворчание), реакция на проверку подключения GitHub/LLM, возвращение сети.
- Тест `tests/mascot.test.ts`: полнота таблиц настроений, шесть персонажей с уникальными репликами, круглые числа и приветствия.
- Процедурная Three.js-модель маскота Лимон (`mascot-3d/`, отдельный npm-пакет вне приложения): фабрика `lemon/src/createLemonMascotModel.ts` по данным `lemon.spec.json` (генерирует `lemon/tools/build_spec.py` из спеки img2threejs), позы «машет» и покоя, взгляд, взмах, разборка на части и выбор части кликом; перчатки с четырьмя пальцами (три + большой), большой козырёк кепки смотрит вверх-влево и показывает тёмную изнанку, как на референсе; просмотрщик-стенд съёмки `npm --prefix mascot-3d run dev` (:5190, конфигурация `mascot-3d` в `.claude/launch.json`); снимки и отчёты гейтов — в `lemon/renders/` и `lemon/evidence/`.

### Changed
- `scripts/mascot-sprites.mjs` больше не читает исходный `aaccbfbeec00f7be2cac9b0693ab91ae.jpg`: Карась режется из листа 3×2 на чёрном (просветы между ногами отличаются от зрачков по соседству с заливкой), Глобус — по рамкам из двух листов на прозрачном фоне с очисткой мусора от удаления фона. Тип `Pose` в манифесте теперь собирается из всех поз всех листов; `spriteFor()` возвращает кадры (`frames`).
- `GITLIB_CLIENT_DIR` задаёт папку собранного клиента (`config.ts`); ZIP-архиватор вынесен из `scripts/pack.mjs` в `scripts/lib/zip.mjs` для обоих бандлов. Сборка очищает содержимое папки платформы, а не удаляет её (папку может держать открытый Проводник).
- Каскад карточек библиотеки укладывается в 300 мс вместо 630: появление карточки 250 мс (было 500), шаг 30 мс (было 45), не больше 10 шагов (было 14); размерная линия прочерчивается за 250 мс через 150 мс после карточки. Вся библиотека на экране за 0,7 с вместо 1,4.
- Токены движения в `:root`: `--dur-quick` (150 мс), `--dur-base` (250 мс), `--dur-slow` (350 мс) и кривая ухода `--ease-in`. Все переходы и появления интерфейса на токенах и с явной кривой; копии пружины у маскота заменены на `--ease-spring`, тост входит с `--ease-out` вместо `ease`.
- Пунктир под активным пунктом навигации прочерчивается один раз при переходе на раздел вместо бесконечного «бега»; пульс индикатора сети — отдельное кольцо на `transform`/`opacity` вместо анимации `box-shadow`.
- Полоса языков на странице репозитория прочерчивается одной линией слева направо (`clip-path`, 350 мс) вслед за панелью, а не растёт отдельными кусками.
- Смех маскота: три смешка по 350 мс и снова дыхание вместо бесконечной частой тряски.
- Длительности по типу элемента: подпись листа, заголовок, шапка репозитория и панели появляются за 250 мс (было 500–550), значок логотипа при наведении — 250 мс (было 500), полоса языков растёт за 350 мс (было 600), наведение и нажатие — 150 мс.
- Маскоты теперь — сами стикеры из референсов `маскот/`, а не перерисовка: скрипт `scripts/mascot-sprites.mjs` вырезает персонажей из листов `Лимон.png`, `Кот.png`, `Банан.png`, `Баскет.png` (шесть поз каждый: машет, палец вверх, бежит, сидит, думает, ликует), убирает фон и кладёт WebP в `src/client/mascot/sprites/` с типизированным манифестом; Глобус и Карась вырезаны из исходного листа (одна поза). Поза выбирается по настроению (`POSE_FOR_MOOD`), общий реквизит (zzz, лупа, сердца, конфетти…) и движения тела сохранены. «Мишка» из первой версии оказался Лимоном, «Кролик» — Котом; сохранённый в браузере выбор `bear`/`rabbit` переводится в `lemon`/`cat`.
- Визуальная идентичность «чертёж библиотеки» по референсам `дизайн/`: миллиметровка и рамка листа вместо точечного фона, штамп-подзаголовок у логотипа, нумерованные разделы в навигации с «бегущей» пунктирной подчёркивающей линией, подпись листа («Лист 01 · каталог · дата») над заголовками, выносные подписи с точкой и линией у секций фильтров, карточки с номером «№ 001», метками обреза и жёсткой тенью при наведении, размерная линия вместо строки метрик, штампы статусов, штриховка вместо мерцающего скелетона, линованный лист в заметках, нумерованные панели на странице репозитория, жёсткие «печатные» тени у кнопок и чипов, квадратные углы.
- Тёмная тема переработана в «синьку» (цианотипию чертежа): тёмно-синяя бумага, светло-кобальтовые линии.
- Анимации появления: карточки выезжают каскадом, размерные линии «прочерчиваются», заголовок листа всплывает, панели репозитория появляются по очереди, полоса языков растёт; индикатор сети пульсирует как узел на схеме.
- Реакции на действия стали разнообразнее: сводка готова → праздник, сбой AI → головокружение, дубликат → смех, экспорт → «крутой», тёмная тема → очки, заметка/снятие звёздочки → смущение, смена статуса и сохранение настроек → подмигивание.
- Реплика «Сбой обновления» вынесена в `phrases.refreshFailed`; `hold()` принимает массив реплик.
- Зависимости обновлены ради закрытия уязвимостей из `npm audit` (теперь 0): `@fastify/static` 8 → 10, `zod` 3 → 4, `vitest` 3 → 5. Под новые API: `setHeaders` выставляет заголовки через `reply.header`, `z.record` в схеме импорта принимает явный тип ключа, `execArgv` в `vitest.config.ts` перенесён на верхний уровень.

### Fixed
- Карточка при наведении снова плавно приподнимается: анимации появления (`fade-up`, `card-in`, `dim-draw`, `bar-grow`) используют `fill-mode: backwards` вместо `both` и после окончания не удерживают `transform`.
- Настройка «уменьшить движение» (`prefers-reduced-motion`) учитывается во всём приложении, а не только у маскота: появления — только прозрачностью за 150 мс, фоновые петли (пунктир навигации, пульс сети, штриховка скелетона) стоят, наведение и нажатие не сдвигают элементы, спиннер крутится медленнее.
- Dev-режим: Vite-прокси `/api` больше не перехватывает модули клиента `src/client/api/*.ts` (они отдавались сервером как `video/mp2t`, и страница не загружалась).

### Removed
- SVG-тела персонажей, общее рисованное лицо и выражения `EXPR` — заменены спрайтами из референса.
- Маскот «Том» (том книги) заменён шестью персонажами из референса.

## [1.0.0] — 2026-10-27

Первая рабочая версия. Исходная точка проекта — пустая папка с визуальными референсами (`дизайн/`, `иконки/`, `маскот/`).

### Fixed
- `index.html` отдаётся с `Cache-Control: no-cache`, а несуществующие `/assets/*` получают 404 вместо SPA-fallback — после пересборки открытая вкладка больше не ломается на старых хешах ассетов.

### Added
- Сервер на Fastify 5 + `node:sqlite`: хранилище записей (три независимых блока `github` / `analysis` / `user`), коллекции, настройки в `data/settings.json`.
- Добавление репозитория по ссылке или `owner/repo`: нормализация всех форм ввода (https, git@, ssh, `.git`, `/tree/...`), дедупликация без учёта регистра, проверка канонического имени после переименования на GitHub.
- Загрузка метаданных, README (raw) и языков через GitHub REST API с опциональным токеном; понятные ошибки для 404 / лимита / отсутствия сети; аватары владельцев сохраняются локально в `data/avatars/`.
- AI-анализ через любой OpenAI-совместимый эндпоинт (base URL, модель, ключ опционален): сводка на русском, сценарии использования, предложенные темы. Фоновая очередь, статусы `none/pending/done/failed`, повтор анализа, восстановление очереди после перезапуска. Автоматический откат на запрос без `response_format`, если эндпоинт его не поддерживает.
- Поиск без учёта регистра с поддержкой кириллицы и «ё» по имени, описанию, темам, сводке, сценариям и заметкам; комбинируемые фильтры по темам, языкам, статусам, избранному, коллекции и отсутствию анализа; сортировки; фасеты.
- Личные данные: заметки с автосохранением, редактируемые темы (свои + GitHub + предложенные AI), статусы «Входящие / Хочу попробовать / Использую / Отложено», избранное, коллекции.
- Экспорт библиотеки в JSON (формат `gitlib-library` v1, включая README и аватары) и импорт с валидацией (zod), предпросмотром и стратегиями для дубликатов: объединить / пропустить / заменить.
- Клиент на React 19 + Vite: страницы «Библиотека», «Репозиторий», «Коллекции», «Настройки»; состояние фильтров в URL; светлая и тёмная темы; состояния загрузки, ошибок и пустой библиотеки; офлайн-индикатор; горячая клавиша `/` для поиска. Шрифты упакованы локально.
- Адаптивная вёрстка: на узких экранах фильтры сворачиваются под кнопку «Фильтры», страница репозитория переходит в одну колонку.
- Маскот «Том» (том книги): SVG-персонаж с настроениями (idle, thinking, happy, sad, search, sleep, love, surprised) и репликами на действия пользователя.
- Тесты Vitest: нормализация и дедупликация, поиск с кириллицей, сохранность пользовательских данных при обновлении и повторном анализе, экспорт/импорт, REST API.
- Скрипты: `scripts/smoke.mjs` (production smoke без сети), `scripts/mock-llm.mjs` (мок OpenAI-совместимого API).
- Обвязка для Claude Code: `CLAUDE.md`, правила `.claude/rules/`, агенты `.claude/agents/` (reviewer, qa, ux), навыки `.claude/skills/` (feature, release, run), `.claude/launch.json`, `.claude/settings.json`; GitHub Actions `ci.yml`.
- README с инструкциями по запуску, интеграциям, расположению данных, резервному копированию и восстановлению.
