## [Unreleased]

## [1.0.0] — 2026-10-27

Первая рабочая версия. Исходная точка проекта — пустая папка с визуальными референсами (`дизайн/`, `иконки/`, `маскот/`).

### Fixed
- `index.html` отдаётся с `Cache-Control: no-cache`, а несуществующие `/assets/*` получают 404 вместо SPA-fallback — после пересборки открытая вкладка больше не ломается на старых хешах ассетов.

### Added
- Сервер на Fastify 5 + `node:sqlite`: хранилище записей (три независимых блока `github` / `analysis` / `user`), коллекции, настройки в `data/settings.json`.
- Добавление репозитория по ссылке или `owner/repo`: нормализация всех форм ввода (https, git@, ssh, `.git`, `/tree/...`), дедупликация без учёта регистра, проверка канонического имени после переименования на GitHub.
- Загрузка метаданных, README (raw) и языков через GitHub REST API с опциональным токеном; понятные ошибки для 404 / лимита / отсутствия сети; аватары владельцев сохраняются локально в `data/avatars/`.
- AI-анализ через любой OpenAI-совместимый эндпоинт (base URL, модель, ключ опционален): сводка на русском, сценарии использования, предложенные темы. Фоновая очередь, статусы `none/pending/done/failed`, повтор анализа, восстановление очереди после перезапуска. Автоматический откат на запрос без `response_format`, если эндпоинт его не поддерживает.
- Поиск без учёта регистра с поддержкой кириллицы и «ё» по имени, описанию, темам, сводке, сценариям и заметкам; комбинируемые фильтры по темам, языкам, статусам, избранному, коллекции и отсутствию анализа; сортировки; фасеты.
- Личные данные: заметки с автосохранением, редактируемые темы (свои + GitHub + предложенные AI), статусы «Входящие / Хочу попробовать / Использую / Отложено», избранное, коллекции.
- Экспорт библиотеки в JSON (формат `gitlib-library` v1, включая README и аватары) и импорт с валидацией (zod), предпросмотром и стратегиями для дубликатов: объединить / пропустить / заменить.
- Клиент на React 19 + Vite: страницы «Библиотека», «Репозиторий», «Коллекции», «Настройки»; состояние фильтров в URL; светлая и тёмная темы; состояния загрузки, ошибок и пустой библиотеки; офлайн-индикатор; горячая клавиша `/` для поиска. Шрифты упакованы локально.
- Адаптивная вёрстка: на узких экранах фильтры сворачиваются под кнопку «Фильтры», страница репозитория переходит в одну колонку.
- Маскот «Том» (том книги): SVG-персонаж с настроениями (idle, thinking, happy, sad, search, sleep, love, surprised) и репликами на действия пользователя.
- Тесты Vitest: нормализация и дедупликация, поиск с кириллицей, сохранность пользовательских данных при обновлении и повторном анализе, экспорт/импорт, REST API.
- Скрипты: `scripts/smoke.mjs` (production smoke без сети), `scripts/mock-llm.mjs` (мок OpenAI-совместимого API).
- Обвязка для Claude Code: `CLAUDE.md`, правила `.claude/rules/`, агенты `.claude/agents/` (reviewer, qa, ux), навыки `.claude/skills/` (feature, release, run), `.claude/launch.json`, `.claude/settings.json`; GitHub Actions `ci.yml`.
- README с инструкциями по запуску, интеграциям, расположению данных, резервному копированию и восстановлению.
